# RadarNet_FMCW_DSP_CNN_RTL
RTL design and verification repository for an FPGA-based Radar DSP–CNN accelerator. Includes VHDL/SystemVerilog modules for AXI4-Stream interfaces, FFT processing, data buffering, and CNN acceleration, along with SystemVerilog testbenches for functional verification. Target platform: PYNQ-Z2 (Zynq-7000 SoC).
